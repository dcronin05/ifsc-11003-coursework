# M4 | Assignment - Progressive CSS Website Project

## Overview

Throughout Module 4, you have progressively enhanced a website by applying modern CSS techniques. This project serves as the culminating activity for the module and demonstrates your ability to apply CSS concepts to create a responsive, accessible, and visually effective website.

## Project Requirements

Your completed website should demonstrate the concepts covered in Module 4, including:

- External stylesheet implementation
- Appropriate use of CSS selectors
- Effective use of the Box Model, margins, and padding
- Flexbox for layout and alignment
- Consistent typography and color usage
- Responsive design using media queries

You are encouraged to personalize your website through design choices, content modifications, images, color schemes, or additional CSS features. Customization is optional and is not required to earn full credit.
